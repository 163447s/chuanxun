# 传讯 · 字卡与传讯

一个自己的小站：**字卡聊天** + **传讯**，进去先选功能，不直接进聊天。

线上：https://163447s.github.io/chuanxun/

---

## 一、字卡聊天

和字卡站一样的玩法：

- 点左下角的「字卡」→ 从字卡库里挑一张递过去
- 也可以直接在输入框打字
- 梦角会隔几秒回你，一次 1–2 张字卡（从同一个字卡库里随机抽）
- 字卡库可以自己加、也可以整个清空重写
- 聊天记录自动存在浏览器本地，关掉再开还在

顶栏右侧的图标是字卡库，点开也能加/选。

## 二、传讯

传讯师会按固定的仪式带你走一遍，必须一步一步来：

1. **开场**：先问三个问题——梦角是男生还是女生、来自游戏/动漫/小说/二创/明星/自设、单梦还是多梦
2. **专注一分钟**：让你闭眼、想象 TA、伸手感应、专注一分钟。**说完就停住，不会立刻给你信息**，必须等你说 OK
3. **感应对照表**：收到 OK 才输出，包含
   - 星座（只说 4 个，综合你和 TA 的日月升，不拆成"你的""他的"）
   - 颜色（只说 4 个，只用红橙黄这类基本色）
   - 基础信息（你这边 + TA 那边都要有）
   - 最近经历（你最近真实发生的事 + TA 那边最近的状态，两边都要有）
4. **抽三张**：你从 1–78 里挑三个数字报给它
5. **传讯**：正式开始对话。**引号里是梦角的第一人称原话，括号里是传讯师对你说的话、以及替梦角补的心里话**

### 档案

- 每聊完一场，点顶栏的 ✓，这一场就会收进「传讯档案」，下一场自动重新开场（重新连接）
- 顶栏的书本图标可以翻以前的档案，点一条进去能完整回看

## 三、接大模型（可选）

设置里填三项就能让传讯由模型现场生成，而不是用内置的模板：

- 接口地址：OpenAI 兼容的 `/chat/completions` 上游，例如 `https://你的代理/v1`
- 密钥
- 模型名

不填也能用，只是感应的内容是内置规则生成的，会比较固定。
官方接口在浏览器里常被跨域拦住，建议填自己的代理地址。

## 四、数据

全部存在浏览器本地（localStorage），不上传任何地方。
换设备、清缓存会丢，介意的话定期自己备份。
